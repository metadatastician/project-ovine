== How to read this file

This is a *verbatim capture of the owner's stated design intent*, recorded
2026-08-05. It is not a specification, not a plan, and not a prioritised
backlog. Ordering carries no meaning.

[IMPORTANT]
====
*Do not paraphrase the entries below.* Restate them and you will layer new
meaning onto them while sounding faithful — which is the specific failure this
estate has recorded before. If an entry is unclear, ask; do not improve it.
Quote it, or leave it alone.

Nothing here is committed to. These are things to *try*, over — in the owner's
words — "obviously, a long time". Some will be discarded, and discarding them
is a result, not a failure.
====

== Why the repo exists

`project-ovine` is a game, but its major role is as a testing ground for the
enaction-engine's *cognitive, affective and conative* AI. That is what `CAC` in
`CACBrainComponent` and `CACSystem` stands for.

The Three.js code in `index.html` and `src/*.js` is a *mockup*, deliberately. It
exists to design the game by trialling how it might look first, to think about
the issues in responses to things, and to work out which behaviours are worth
capturing, modelling, or potentially discarding. A proper implementation in
Rust / a proof language is to be written alongside it. The mockup is meant to
stay cheap to change and cheap to throw away.

== What is deliberately NOT recorded here

No sequencing, no increments, no acceptance criteria, no data model. Those are
decisions that have not been taken, and writing them here would make taken
decisions out of untaken ones.

== Working through these

Each entry gets its own working document under `docs/design/logics/`, produced
and driven by `scripts/ovine-design.sh`. The intended loop is *one entry per
fresh Claude thread*, because a long thread is where restatement drift
accumulates.

[source,console]
----
bash scripts/ovine-design.sh list          # what is worked up, what is not
bash scripts/ovine-design.sh next          # next entry with no working document
bash scripts/ovine-design.sh start ov-03   # create it, quote copied in by machine
bash scripts/ovine-design.sh brief ov-03   # paste-ready brief for a fresh thread
bash scripts/ovine-design.sh check         # drift detector — run before committing
----
