== The honest state (one breath)

At the anchor, the golden path named in `CLAUDE.md`, `just test && just
quality`, fails at its first step. `just test` is still the template stub and
exits 1 by design. Most other Justfile recipes are template stubs that print
a TODO and exit 0. The browser simulation has no tests. Its local modules
resolve and bundle with Bun. The Idris2 ABI builds. The Zig FFI has no build
targets, and its source does not compile. The Agda and Coq proofs check.
The Lean gate checks nothing, and the Idris2 gate checks one file of six.

=== What is solid (and how we checked)

* `bun build src/main.js --target browser --external three` succeeds and
  writes a 26.72 KB bundle. All local imports in the simulation resolve, and
  the code parses. Nothing here checks its behaviour.
* `idris2 --typecheck abi.ipkg` builds all 3 ABI modules (`Abi.Types`,
  `Abi.Layout`, `Abi.Foreign`). The log was read for `Error:`, not just the
  exit code. There were no errors, and two shadowing warnings in `Abi.Layout`,
  both for the implicit `n` at lines 87 and 89.
* `scripts/check-proofs.sh agda` and `scripts/check-proofs.sh coq` pass.
  `Properties.agda` compiles under `agda --safe`, and `TypeSafety.v` compiles
  under `coqc`. Each is the only gated file for its language.
* `just verify` passes ("All OpenSSF Best Practices prerequisites satisfied",
  27 workflows). `just must-check` passes.
* `tests/workflows/validate_workflows_test.sh` passes with 0 errors and 6
  warnings. Three recommended workflows are absent: `instant-sync.yml`,
  `npm-bun-blocker.yml` and `ts-blocker.yml`.
* On the anchor commit's GitHub status check rollup (read over the GraphQL
  API), 23 of 30 contexts concluded `SUCCESS`. These are mostly scanners and
  policy checks over the tree. None tests the simulation.

=== The honest nuance you must not lose

* *Most green Justfile recipes here mean nothing.* `just lint`, `just
  fmt-check`, `just aspect` and `just e2e` exit 0, but each recipe body is
  the template's `# TODO: Replace with …` comments followed by an `echo` of
  success. `just build` is the same kind of stub. None of them runs a tool.
* *The real aspect test fails, but on a false positive.* `bash
  tests/aspect_tests.sh` reports PASS=2 FAIL=1. The failing check greps
  `src/` and `verification/` for `Admitted`, `sorry` and `unsafeCoerce`. All
  four hits are prose that *forbids* those constructs:
  `verification/proofs/README.adoc:48–50` and a comment at
  `coq/TypeSafety.v:6`. No banned proof escape was found in code.
* *A green Lean gate here means nothing.* `scripts/check-proofs.sh lean4`
  exits 0, but its only file, `ApiTypes.lean`, is quarantined as
  expected-fail ("has never compiled"; `Nat.zero_le max` at line 44).
* *The Idris2 verification gate passes one file.* Only `ABI/Foreign.idr` is
  gated, and it checks. Five files are quarantined as expected-fail, each
  with a recorded reason: `Types.idr`, `ABI/Layout.idr`, `ABI/Platform.idr`,
  `ABI/Pointers.idr` and `ABI/Compliance.idr`.
* *The repository's `mise.toml` is untrusted on a fresh machine.* mise warns
  on every tool call. These checks ran with the mise shims removed from

== Reproduce it yourself

From a clone checked out at the anchor commit:

[source,bash]
----
git checkout 90f963c1c078ff3c8fc43b03dc8adadaf02472c1
just test                                   # rc=1: template stub
just --show lint                            # a TODO comment and an echo
bun build src/main.js --target browser --external three --outfile /tmp/ovine.js
idris2 --typecheck abi.ipkg                 # look for "Error:", not the exit code
(cd src/interface/ffi && zig build test)    # no step named 'test'
(cd src/interface/ffi && zig test -lc src/main.zig)   # main.zig:44 opaque fields
for p in agda coq lean4 idris2; do bash scripts/check-proofs.sh "$p"; done
bash tests/aspect_tests.sh                  # PASS=2 FAIL=1 (prose hits)
for t in tests/workflows/*.sh tests/e2e/*.sh; do bash "$t"; done
just verify must-check
----

If `mise` shims are on your `PATH` and you have not trusted this repository's
`mise.toml`, remove them from `PATH` first.

Agda needs agda-stdlib. Point `AGDA_DIR` at a directory whose `libraries` file
names the stdlib's `.agda-lib` and whose `defaults` file says
`standard-library`.
